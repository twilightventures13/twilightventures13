# twilight ventures

Data file viewers for JetBrains IDEs, VS Code, Confluence and Jira. Each one opens a big file in place and pages through it instead of loading it whole; reading is free and Pro is the paid tier.

Website: https://twilightventures.dev · Support: support@twilightventures.dev · Bugs and requests: https://github.com/twilightventures13/lens/issues

## JetBrains IDEs

- [JSONL Lens](https://plugins.jetbrains.com/plugin/33397): JSON Lines and NDJSON, gzipped included
- [Log Lens](https://plugins.jetbrains.com/plugin/33416): large plain, JSON lines, logfmt and ANSI logs, with follow mode
- [Parquet Lens](https://plugins.jetbrains.com/plugin/33510): Parquet, Avro, TFRecord, Arrow and Feather datasets
- [SQLite Lens](https://plugins.jetbrains.com/plugin/33684): a read-only SQLite database browser
- [XLSX Lens](https://plugins.jetbrains.com/plugin/33721): Excel workbooks, streamed and read-only
- [Notebook Lens](https://plugins.jetbrains.com/plugin/33811): Jupyter notebooks as documents, no kernel needed
- [DuckDB Lens](https://plugins.jetbrains.com/plugin/33853): a read-only DuckDB database browser
- [Heap Dump Lens](https://plugins.jetbrains.com/plugin/33908): JVM heap dumps, thread dumps and GC logs

## VS Code

- [JSONL Lens](https://open-vsx.org/extension/twilightventures/jsonl-lens), [Parquet Lens](https://open-vsx.org/extension/twilightventures/parquet-lens-viewer) and [Log Lens](https://open-vsx.org/extension/twilightventures/log-lens) on Open VSX and the Visual Studio Marketplace; one Lens Pro key covers the three, with a 30-day trial on each machine.

## Confluence and Jira

- [Lens File, Log, & Attachment Viewer for Jira](https://marketplace.atlassian.com/apps/249455342/lens-file-log-attachment-viewer-for-jira): attachments on an issue open as paged tables, read as the viewing user
- Lens File Viewer for Confluence: the same for a Confluence page, in review on the Atlassian Marketplace

Every product page, the guides, the pricing and the policies are on the website. The store terms, the privacy policy and the security policy live in the [lens](https://github.com/twilightventures13/lens) repository.

## Suggestions and bug reports

Every plugin has an issue reporter in the Help menu that shows you the full text before anything is sent. Suggestions of any size are welcome there, or as an issue on the lens repo.
